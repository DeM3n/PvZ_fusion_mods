# Technical Documentation: Environment Setup & Reverse Engineering

This guide covers the necessary tools, assembly extraction process, and project configuration required to develop mods for **Plants vs. Zombies Fusion** (Unity Il2Cpp).

---

## 1. Technical Overview

* **Engine:** Unity.
* **Compilation Target:** **Il2Cpp** (Intermediate Language to C++). Unlike classic PvZ or Mono-based Unity titles where managed assemblies execute on a CLR virtual machine, PvZ Fusion compiles C# source code into C++ and subsequently into native machine code.
* **Modding Framework:** **MelonLoader** (x64 Il2Cpp). MelonLoader restores metadata and provides an interop layer (`Il2CppInterop`) allowing managed C# code to interface with native game memory.

---

## 2. Prerequisites

1. **.NET 6.0 SDK:** Required for compiling mod libraries. MelonLoader modern runtimes target .NET 6.0.
2. **MelonLoader (x64 Il2Cpp build):** The core mod loader for the game.
3. **Decompiler / Metadata Viewer:**
   * **DnSpy** or **ILSpy**: Used to inspect classes, enumerations, methods, and field offsets in restored game assemblies.
4. **Development Environment:** Visual Studio 2022, JetBrains Rider, VS Code, or Antigravity.

---

## 3. Extracting Game Assemblies

To reference game types and invoke internal functions, you must obtain the interop assemblies generated by MelonLoader.

### Procedure:
1. Install **MelonLoader** into the root directory of the PvZ Fusion installation.
2. Launch the game executable once. MelonLoader reads `global-metadata.dat` and generates type-safe C# wrapper assemblies inside:
   ```
   <GameDirectory>/MelonLoader/Il2CppAssemblies/
   ```
3. Copy the necessary assemblies into your mod project dependencies directory (`lib/`):

| Assembly File | Target Location | Description |
| :--- | :--- | :--- |
| `Assembly-CSharp.dll` | `lib/Game/` | Primary game logic: plant classes, zombie logic, board management, bullet behaviors, and global helper functions. |
| `UnityEngine.CoreModule.dll` | `lib/Game/` | Core Unity engine types (`GameObject`, `Transform`, `Vector3`, `Time`). |
| `Il2Cppmscorlib.dll` | `lib/Game/` | Il2Cpp system and primitive definitions. |
| `MelonLoader.dll` | `lib/MelonLoader/` | Mod entry point, logger, lifecycle events (`MelonMod`). |
| `0Harmony.dll` | `lib/MelonLoader/` | Method patching and hooking infrastructure. |
| `Il2CppInterop.Runtime.dll` | `lib/MelonLoader/` | Memory pointer management and type casting between managed C# and native C++. |

---

## 4. Decompilation & Code Inspection

1. Launch **DnSpy** or **ILSpy**.
2. Open `lib/Game/Assembly-CSharp.dll`.
3. Inspect the `Il2Cpp` namespace:
   * `Board`: Board singleton, grid coordinates, and entity container references.
   * `Plant`: Base class for all plant entities.
   * `PlantType`: Enumeration covering every standard and fused plant type.
   * `Zombie`: Base class for zombie entities.
   * `ZombieType`: Enumeration defining all zombie types.
   * `Lawnf`: Static utility class containing modifier checks, coordinate transforms, and gameplay calculations.
   * Individual plant classes: `UltimateHypno`, `UltimateGatling`, `PeaSunFlower`, etc.

## 5. Project Configuration (.NET 6.0)

Below is the standard `.csproj` configuration for building MelonLoader mods against Il2Cpp assemblies:

```xml
<Project Sdk="Microsoft.NET.Sdk">

  <PropertyGroup>
    <TargetFramework>net6.0</TargetFramework>
    <ImplicitUsings>enable</ImplicitUsings>
    <Nullable>enable</Nullable>
    <AppendTargetFrameworkToOutputPath>false</AppendTargetFrameworkToOutputPath>
    <OutputPath>bin\$(Configuration)\</OutputPath>
  </PropertyGroup>

  <ItemGroup>
    <!-- MelonLoader References -->
    <Reference Include="MelonLoader">
      <HintPath>..\..\lib\MelonLoader\MelonLoader.dll</HintPath>
      <Private>false</Private>
    </Reference>
    <Reference Include="0Harmony">
      <HintPath>..\..\lib\MelonLoader\0Harmony.dll</HintPath>
      <Private>false</Private>
    </Reference>
    <Reference Include="Il2CppInterop.Runtime">
      <HintPath>..\..\lib\MelonLoader\Il2CppInterop.Runtime.dll</HintPath>
      <Private>false</Private>
    </Reference>

    <!-- Game Interop References -->
    <Reference Include="Assembly-CSharp">
      <HintPath>..\..\lib\Game\Assembly-CSharp.dll</HintPath>
      <Private>false</Private>
    </Reference>
    <Reference Include="UnityEngine.CoreModule">
      <HintPath>..\..\lib\Game\UnityEngine.CoreModule.dll</HintPath>
      <Private>false</Private>
    </Reference>
    <Reference Include="Il2Cppmscorlib">
      <HintPath>..\..\lib\Game\Il2Cppmscorlib.dll</HintPath>
      <Private>false</Private>
    </Reference>
  </ItemGroup>

</Project>
```

## 6. Minimal Mod Implementation

```csharp
using MelonLoader;
using Il2Cpp;
using UnityEngine;

[assembly: MelonInfo(typeof(MyPvZMod.MainMod), "Example Mod", "1.0.0", "Author")]
[assembly: MelonGame(null, null)]

namespace MyPvZMod
{
    public class MainMod : MelonMod
    {
        public override void OnInitializeMelon()
        {
            LoggerInstance.Msg("Mod initialized successfully.");
        }

        public override void OnUpdate()
        {
            // Update loop logic
        }
    }
}
```
